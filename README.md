# موقع مجموعة السلام القابضة (ASG)

الموقع الرسمي لـ **مجموعة السلام القابضة (Al Salam Holding Group)** — موقع تعريفي بالكامل باللغة العربية (RTL)، يعرض الشركة الأم وشركاتها الأربع (ASC، ASCD، ASRD، OSWA)، خدماتها، مشاريعها، شركاؤها، وبيانات التواصل.

**الشعار:** من المعرفة إلى التجربة... ومن التجربة إلى الأثر

---

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| [Vite](https://vitejs.dev/) | أداة البناء والتشغيل (Dev Server + Build) |
| [React 18](https://react.dev/) + TypeScript | بناء الواجهة |
| [React Router v6](https://reactrouter.com/) | التنقل بين الصفحات |
| [Tailwind CSS](https://tailwindcss.com/) | التنسيق والتصميم |
| [shadcn/ui](https://ui.shadcn.com/) (Radix UI) | مكوّنات الواجهة الجاهزة (Accordion, Dialog, Toast...) |
| [lucide-react](https://lucide.dev/) | الأيقونات |

---

## المتطلبات قبل التشغيل

- [Node.js](https://nodejs.org/) إصدار **18 أو أحدث** (تم تطوير المشروع واختباره على Node 24).
- `npm` (يُثبّت تلقائيًا مع Node.js).

---

## طريقة التشغيل (خطوة بخطوة)

```sh
# 1. ادخل على فولدر المشروع (peaceful-web)
cd peaceful-web

# 2. ثبّت المكتبات المطلوبة (أول مرة بس، أو بعد أي تحديث في package.json)
npm install

# 3. شغّل سيرفر التطوير المحلي
npm run dev
```

بعد تشغيل الأمر الأخير، هيفتحلك السيرفر على:

```
http://localhost:8080/AscGroup/
```

> ⚠️ **مهم**: لازم يكون الرابط منتهي بـ `/AscGroup/` (مع الـ `/` في الآخر)، لأن الموقع مبني على مسار فرعي بهذا الاسم. فتح `http://localhost:8080/` لوحده هيوديك لنفس الصفحة الرئيسية تلقائيًا، لكن أي رابط داخلي (زي صفحات الشركات أو المشاريع) لازم يبدأ بـ `/AscGroup/`.

السيرفر بيدعم **Hot Reload**: أي تعديل في الكود بيظهر فورًا في المتصفح من غير ما تحتاج تعمل ريفريش يدوي.

### أوامر تانية متاحة

```sh
npm run build       # يبني نسخة الإنتاج النهائية (الموجودة في فولدر dist/)
npm run build:dev   # نفس البناء لكن بإعدادات التطوير (للتجربة فقط)
npm run preview     # يشغّل نسخة الإنتاج المبنية محليًا للمعاينة قبل الرفع
npm run lint        # يفحص الكود بحثًا عن أخطاء بسيطة (ESLint)
```

## خريطة صفحات الموقع

| الرابط | الصفحة |
|---|---|
| `/` | الصفحة الرئيسية (نبذة، رؤيتنا ورسالتنا، الخدمات، هيكل المنظومة، الأثر، القيم، التقنيات، الشركاء، تواصل معنا) |
| `/companies` | صفحة "شركاتنا" — عرض الشركات الأربع |
| `/companies/ASC` | تفاصيل شركة السلام |
| `/companies/ASCD` | تفاصيل السلام للمقاولات والديكورات |
| `/companies/ASRD` | تفاصيل السلام للبحث العلمي والتطوير |
| `/companies/OSWA` | تفاصيل أسوة للهدايا |
| `/projects` | صفحة "مشاريعنا" — عرض كل المشاريع |
| `/projects/:id` | تفاصيل مشروع واحد |

أي رابط غير موجود يوديك تلقائيًا لصفحة 404 بتصميم عربي، وفيها زرار يرجّعك للصفحة الرئيسية.

## هيكل المشروع (أهم الملفات والفولدرات)

```
peaceful-web/
├── src/
│   ├── pages/                    # صفحات الموقع (Index, CompaniesPage, CompanyDetailPage, ProjectsPage...)
│   ├── components/                # أقسام الصفحة الرئيسية (Hero, About, Services, OrgChart, Values...)
│   │   ├── company-layouts/      # تصاميم صفحات تفاصيل الشركات (AscLayout المشترك، OswaLayout الخاص)
│   │   └── ui/                   # مكوّنات shadcn/ui الجاهزة (Accordion, Dialog, Button...)
│   ├── data/
│   │   ├── companies.ts          # بيانات الشركات الأربع الكاملة (الاسم، الوصف، الخدمات، اللوجو)
│   │   └── projects.ts           # بيانات كل المشاريع
│   ├── assets/                   # الصور (اللوجوهات، شعارات الشركاء، هيكل المنظومة)
│   ├── index.css                 # الألوان الرسمية للهوية + التدرّج اللوني + الخطوط
│   └── App.tsx                   # إعداد التوجيه (Routing) بين الصفحات
├── public/                        # الفافيكون وملفات ثابتة أخرى
└── package.json
```

لتعديل محتوى أي شركة أو مشروع (النص، الخدمات، الصور...)، التعديل بيكون في ملفات `src/data/companies.ts` و `src/data/projects.ts` مباشرة، ومفيش داعي تلمس تصميم الصفحات نفسها.

## ملاحظات مهمة قبل نشر الموقع فعليًا

1. **فورم "تواصل معنا"** (في الصفحة الرئيسية) شكله شغال بصريًا، لكنه **مش مربوط فعليًا بأي خدمة إرسال** — أي رسالة تتبعت من خلاله مش هتوصل لحد دلوقتي. لازم يتربط بخدمة إيميل (زي SMTP أو Formspree) قبل الإطلاق لو عايزين الفورم يشتغل فعليًا.
2. **الألوان الرسمية** للهوية (البنفسجي `#5B1990`، التركواز `#226C7B`، الأزرق الفاتح `#8EC3E8`) متأكد منها ومطابقة تمامًا لكتيب الهوية، ومعرّفة مرة واحدة في `src/index.css` — أي تغيير لونى مستقبلي يتعمل من هناك بس.
3. المسار الفرعي `/AscGroup/` معرّف في مكانين لازم يفضلوا متطابقين لو حصل تغيير: `vite.config.ts` (`base`) و`src/App.tsx` (`basename`).
